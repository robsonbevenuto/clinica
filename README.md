O sistema é um gerenciador de clínica médica. As tabelas do banco de dados são:

* **Paciente:** Tabela de pacientes.
* **Medico:** Tabela de médicos.
* **Consulta:** Tabela principal, ligada a Paciente e Medico (chaves estrangeiras).
